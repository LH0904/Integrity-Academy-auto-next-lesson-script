# 诚信学堂自动续播（Chrome）

## 安装

1. 在 Chrome 地址栏打开 `chrome://extensions`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本文件所在的 `诚信学堂自动续播` 文件夹。
5. 回到诚信学堂课程播放页并刷新。页面右上角会出现“自动续播：开启”按钮。

## 使用

- 正常登录课程，手动开始播放第一讲。
- 保持课程标签页在前台。诚信学堂页面会在标签页切到后台时暂停视频。
- 本讲结束后，扩展会点击平台自己的下一讲按钮，让网站保存本讲记录，再读取课程接口核对完成标记、播放进度和累计时长；核验通过后才播放下一讲。
- 如果平台没有确认本讲完成，扩展会尽量返回本讲并停止续播，在页面提示当前进度和累计时长。
- 课程接口无法读取时，扩展会停止续播，避免未核验就跳过课程。
- 如果 Chrome 阻止自动播放，页面状态会提示你手动点击视频播放键。
- 点右上角按钮可以暂停或重新开启；选择会保存在本机浏览器。
- 没有下一讲时会停止并显示“已到最后一讲”。

## 更新或移除

修改扩展文件后，在 `chrome://extensions` 页面点扩展卡片上的刷新按钮。
不再使用时，在该页面移除“诚信学堂自动续播”即可。
