# 诚信学堂自动续播（Chrome）

版本：1.4.0。需要 Chrome 111 或更新版本。

## 安装

1. 在 Chrome 地址栏打开 `chrome://extensions`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择包含 `manifest.json` 的文件夹。
5. 回到诚信学堂课程播放页并刷新。页面右上角会出现“自动续播”和“后台播放”两个开关。

## 使用

- 正常登录课程，手动开始播放第一讲。
- 支持 `/e-training/quality/courselearn`（专业课）和 `/e-training/lecture/courselearn`（公需课/讲座）等 `/e-training/*/courselearn` 学习页；这些路由加载同一个页面组件、调用同一个课程接口。
- “后台播放”默认开启。出现“后台播放已启用”后，可以切换标签页或最小化 Chrome 窗口；手动暂停仍然有效。
- 两个开关独立工作：“自动续播”控制结束后的自动切课，“后台播放”控制页面隐藏时是否触发网站的自动暂停。关闭后台播放开关会恢复网站原来的暂停监听。
- 本讲结束后，扩展会点击平台自己的下一讲按钮，让网站保存本讲记录，再读取课程接口核对完成标记、播放进度和累计时长；核验通过后才播放下一讲。扩展同时监听原生结束事件，并每秒检查播放状态，兼容 Prism/MSE 视频流没有发出原生 `ended` 事件的情况。
- 如果平台没有确认本讲完成，扩展会尽量返回本讲并停止续播，在页面提示当前进度和累计时长。
- 课程接口无法读取时，扩展会停止续播，避免未核验就跳过课程。
- 如果 Chrome 阻止自动播放，页面状态会提示你手动点击视频播放键。
- 点右上角按钮可以暂停或重新开启；选择会保存在本机浏览器。关闭自动续播或手动点击目录切课，会取消待执行的自动续播操作。
- 没有下一讲时会停止并显示“已到最后一讲”。

## 后台播放的适用范围

后台播放功能只解除当前课程组件在页面隐藏时主动暂停视频的监听。刷新页面、切换课程导致组件重建时，扩展会重新应用设置。

浏览器可能延迟后台的计时器和新视频自动播放，扩展为后台加载与进度核验提供了更长的等待时间。若下一讲停在播放按钮处，需要回到页面手动启动。电脑睡眠、合盖或浏览器关闭时无法保证播放。

原型已由用户在真实课程页验证最小化后仍能播放。集成版的监听恢复、重复开关、组件重建和页面离开/恢复已用模拟环境检查；完整后台跨讲播放仍需在实际课程中确认。

## 更新或移除

修改扩展文件后，在 `chrome://extensions` 页面点扩展卡片上的刷新按钮，再刷新课程页。升级到 1.4.0 时请更新整个扩展文件夹：1.4.0 起扩展同时匹配 `quality` 和 `lecture` 两类课程页，旧版本在新开的公需课/讲座页面不会注入。

如果之前在控制台运行过临时验证脚本，刷新课程页后直接使用扩展即可，无需再次运行验证脚本。

不再使用时，在扩展管理页移除“诚信学堂自动续播”，然后刷新已打开的课程页，以清理页面中已注入的代码。

## 开发检查

在本文件所在目录运行 `node tests/background-playback.test.js`；macOS 也可以使用系统 JavaScriptCore：

```sh
/System/Library/Frameworks/JavaScriptCore.framework/Versions/A/Helpers/jsc tests/background-playback.test.js
```

扩展使用 Chrome 的 `MAIN` 执行环境访问页面组件，并由独立的内容脚本管理设置与界面。[Chrome 官方文档](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts)
